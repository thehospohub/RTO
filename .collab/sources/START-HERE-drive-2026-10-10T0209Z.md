Review and director escalation

ChatGPT saves an identified version and records upload verification, then logs a batch handover containing task IDs, file links, source pack, specific review questions and blockers. Claude records findings and reviewed version in Drive. ChatGPT fetches latest findings, corrects or explains disposition with evidence, and requests focused re-review.

After both AI checks have no open material findings, label READY FOR DIRECTOR REVIEW (add this status to the vocabulary). Specialist-dependent items can be READY FOR DIRECTOR REVIEW—SPECIALIST REVIEW PENDING, but remain unapproved for use.

Director brief: decisions needed, actual changes, unresolved assumptions, evidence links, costs/dependencies and approval scope. Do not bury unresolved issues in a long policy. Directors' changes return to controlled revision.

Notify directors in the active chat when a batch is ready; no automatic email or background notification is promised. Weekly brief is generated when the project session is initiated. Sources and future tool availability must be rechecked where necessary.

Execution cadence and cost controls

Work in batches of up to five policy bundles, or one/two units depending on size. Initial targets are tested rather than assuming five policies per day. Separate active drafting and review turns; maximum two review rounds before exception escalation. Start within existing subscriptions; track usage limits and actual effort. No new paid system is assumed.

At each initiated session: read latest handover; execute highest-priority unblocked task; save/verify; update register and review request; report completed work and next owner. Neither AI is assumed to watch Drive continuously.
